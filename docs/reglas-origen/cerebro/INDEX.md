# 🧠 CEREBRO — la memoria que gobierna los muros

Este vault NO es documentación: **los scripts lo leen**. Las notas de `cuentas/`, `reglas/globales` y
`lecciones/` llevan bloques ```datos``` que `EDITOR/cerebro.py` entrega a las puertas en cada generación.
**Escribir una línea aquí cambia el comportamiento del sistema.** Cada corrección de Emmanuel está
obligada (hook Stop) a convertirse en una lección aquí — así se alimenta solo.
