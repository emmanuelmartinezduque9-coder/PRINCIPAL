# Automatizar no es añadir formularios

Emmanuel rechazó la pestaña Granja: pedía que todo el sistema fuera una fábrica de
vídeos, no una pantalla llena de explicaciones y trabajo manual. Crear registros
para que él copie métricas no resuelve el cuello de botella.

Regla permanente: no añadir secciones, dashboards ni formularios no solicitados.
Cada cambio de interfaz debe eliminar una acción real del usuario; mantenerla
breve y dentro del flujo existente. Primero conectar y comprobar datos reales de
redes sociales; después construir el aprendizaje sobre ellos, no sobre simulaciones.

Corrección: retirar pestaña/iframe Granja y su acceso estático. Los enlaces antiguos
van a Montaje. Conservar transcripciones, fuentes y datos; no confundir retirar una
interfaz con borrar conocimiento. Mantener funciones internas útiles sin exigir que
Emmanuel alimente otra pantalla. Investigar Trendtrack ya contratado antes de
recomendar otra suscripción. No afirmar que la API de inteligencia competitiva
equivale a acceso a las estadísticas privadas de sus cuentas.

Comprobación: prueba de regresión de navegación sin Granja, redirección de enlaces
antiguos y verificación de fuentes. No tocar las puertas de frames o vídeo.
