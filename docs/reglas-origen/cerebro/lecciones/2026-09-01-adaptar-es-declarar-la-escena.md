# adaptar-es-declarar-la-escena

**Fecha:** 2026-09-01 · **Ámbito:** GLOBAL
**Qué pasó:** Al adaptar el 1,2,3 de tienda a dormitorio cambie quien habla y deje both employees, the cart y un palet de cajas apiladas con una sola mujer
**Regla:** Adaptar un prompt = declarar la ESCENA (personas, lugar, objeto) y dejar que el contrato coteje el texto final; nunca fiarse de haber cambiado unas frases

 "checklist_frames": [
  "cada elemento del prompt es coherente con la escena: numero de personas, lugar y cantidad de objetos"
 ]
