# los-frames-tambien-tienen-puerta

**Fecha:** 2026-09-02 · **Ámbito:** GLOBAL
**Qué pasó:** 
**Regla:** La generacion de FRAMES pasa por EDITOR/frame.py, igual que el video pasa por lanzar.py. Prohibido llamar a nano_banana_pro a mano. En el lote se declara que SE VE (en_pantalla) y el script adjunta las imagenes; si el prompt dice que el producto queda OCULTO, su imagen NO se adjunta. La referencia de REALISMO es solo de estilo y el prompt tiene que decirlo con REALISM REFERENCE ONLY, o el modelo copia sus objetos.

```datos
{
 "checklist_frames": [
  "si el producto queda tapado u oculto en el frame, no se adjunta ninguna imagen suya: solo se declara el motivo"
 ]
}
```
