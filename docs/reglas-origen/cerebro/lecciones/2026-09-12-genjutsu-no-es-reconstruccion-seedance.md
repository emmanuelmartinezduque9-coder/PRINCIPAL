# No trasladar requisitos entre motores sin una razón funcional

El control universal de escenas convirtió el Q&A nativo de Memories en requisito
para Genjutsu, aunque Object Swap recibe el vídeo original como autoridad de movimiento.
Emmanuel señaló esa confusión y autorizó separar los controles: revisión de edición
para Genjutsu y datos disponibles de API para Seedance, manteniendo calidad independiente.

La capacidad ausente de un proveedor no debe bloquear una ruta que no la necesita.
La solución no es falsear el tipo de evidencia ni quitar toda revisión; es comprobar
lo apropiado para cada motor y probar que fuentes incorrectas, cambios de referencias
y veredictos de otro envío siguen rechazándose. No reconstruir en un largo prompt los
movimientos que Genjutsu ya recibe, salvo instrucciones de conservación necesarias.
