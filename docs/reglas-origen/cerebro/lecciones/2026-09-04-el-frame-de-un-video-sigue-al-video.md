# el-frame-de-un-video-sigue-al-video

**Fecha:** 2026-09-04 · **Ámbito:** GLOBAL
**Qué pasó:** El 2026-09-04 genere el frame del 1,2,3 de FlauschNest con la tela colgada delante de una pared, cuando en el video la tela TAPA los buzos que luego se revelan. No habia leido que pasa en esa escena antes de escribir el frame. Emmanuel: «levanta un muro de que primero lea el prompt de memories antes de generar el frame para que tenga sentido el frame».
**Regla:** Un frame que sale de un video de Mañana tiene que tener sentido con lo que pasa en esa escena del video: primero se lee el analisis, luego se escribe el frame. Tapiado en frame.py: si la composicion es un fotograma de un lote, hay que declarar «analisis_escena» y el prompt tiene que respetarlo.
