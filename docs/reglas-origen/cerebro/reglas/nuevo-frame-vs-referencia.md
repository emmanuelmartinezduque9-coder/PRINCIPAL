# "Nuevo frame" vs "referencia" — la palabra decide el flujo

Distinción clave en las subidas de la mañana (Emmanuel sube las imágenes agrupadas por cuenta, sin renombrar; yo las mapeo en orden a sus tareas sin pedirle explicaciones):

- **"nuevo frame"** = imagen YA LISTA (un frame terminado, no una referencia). → Usarla DIRECTO como start_image y regenerar el vídeo. NO crear frame, NO aplicar [[reglas/frame-desde-referencia]], NO pedir OK del frame.
- **"referencia" / "crea el frame con esta imagen"** = imagen AJENA (anuncio de otro). → Aplicar el patrón completo de [[reglas/frame-desde-referencia]] (reemplazo de producto, rediseño de fondo…) y parar a que Emmanuel apruebe el frame.

Caso intermedio: **"regenera el frame [grupo] N"** (un frame que ya está en la app = validado) → tratarlo como referencia con cambios: rediseño de objetos de fondo + cambios de luz + más realismo, y lo que él pida. El número N es el del panel: [[reglas/numeros-del-panel-fijos]].

Porqué: un "nuevo frame" ya está aprobado de facto — meterle el patrón o pedirle OK duplica trabajo y toca lo que él ya dio por bueno; una "referencia" es de la competencia y hay que rehacerla como frame propio, nunca usarla tal cual.

Si la variante del frame subido es rosa o azul: [[reglas/variante-de-color]].
