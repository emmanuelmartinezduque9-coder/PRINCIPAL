# Subida de imágenes por la mañana (convención)

- Emmanuel sube las imágenes **agrupadas por cuenta** (todas las de una cuenta, luego las de otra), **sin renombrarlas**.
- Al pedir, nombra la **cuenta** y la **tarea**, y las imágenes ya vienen en el orden que corresponde. Ej: `eiswerk` → "regenerar c1 variante galleta con nuevo frame".
- Claude mapea las imágenes subidas (en su orden) a las tareas listadas, por cuenta. **NO pedirle que explique cada imagen ni que cuide más el orden.** Porqué: la convención existe para no llenarle de preguntas ni hacerle perder tiempo.

**Distinción clave de palabras:**
- **"nuevo frame"** = imagen YA LISTA (un frame terminado, no una referencia) → usarla DIRECTO como start_image y regenerar el vídeo. NO crear frame, NO aplicar [[reglas/frame-desde-referencia]], NO pedir OK del frame.
- **"referencia" / "crea el frame con esta imagen"** = imagen ajena → aplicar el patrón [[reglas/frame-desde-referencia]] (reemplazar producto, rediseño de fondo, etc.).
