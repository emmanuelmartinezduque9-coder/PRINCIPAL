# Réplicas Genjutsu: escena propia por mercado
Para todas las cuentas y nuevas réplicas. Conservar la acción, función, tiempos y posiciones necesarios para transferir el movimiento, pero diseñar desde el primer frame una escena visualmente distinta. Cambiar de forma sustancial y coherente el espacio, distribución, mobiliario, materiales, iluminación, vestuario, personas y elementos secundarios. No basta recolorear el original.
Buscar oportunidades de diferenciación física: si Emmanuel indica otra variante, usar su referencia exacta y respetar forma, tamaño y funcionamiento. Si no indica otra, conservar el producto vendido; variar lo demás sin inventar variantes.
Elegir avatares activos según edad, papel y acción, también para niños. Adaptar vestuario, arquitectura y contexto al mercado sin inferir nacionalidad por el rostro. Para perros se puede usar el PC y consultar Pinterest como referencia de razas plausibles en el país, manteniendo tamaño y capacidades necesarios para la acción; no copiar la fotografía como escenario.
Antes de lanzar el clip, comparar visualmente el frame real con la fuente: registrar qué cambió y comprobar que la acción sigue siendo viable, el producto fiel y el contexto natural. Si parece la misma escena con otro color o rostro, corregir el frame. No modificar trabajos históricos ni garantizar distribución en Instagram.
