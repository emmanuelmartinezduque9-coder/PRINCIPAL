## Qué conservar como método

- Destinatario reconocible + curiosidad: el fijado habla del marido.
- Destinatario reconocible + invitación a compartir: dos publicaciones recientes repiten el amigo alemán y ambas destacan frente al ejemplo de 3.709 de antigüedad cercana.
- El segundo y tercer reel reutilizan el MISMO texto observado: no presentarlos como dos variaciones textuales distintas. Hay repetición de rendimiento, no demostración de que cambiar copy revivió el mismo reel.
- El contraste «solo es un despertador» aparece, pero esta muestra no justifica priorizarlo como ganador.
- Las escenas observadas incluyen demostración de despertador-diana; no copiar elementos, canciones, bromas políticas o identidades solo porque aparezcan en el vídeo/comentarios.

Ejemplos de nuevas adaptaciones alemanas, NO publicaciones observadas ni resultados probados:

- Misma familia de curiosidad: `Zeig das bloß nicht deinem Mann 😂`.
- Variante de destinatario dentro de un ángulo de pareja autorizado: `Zeig das bloß nicht deinem Freund 😂`.
- Compartir por afinidad: `Schick das jemandem, der morgens nie aus dem Bett kommt 😂` (cambia la afinidad cultural por el problema de levantarse; validar que el ángulo corresponda al encargo).

Actualizar la muestra cuando se soliciten textos que funcionen actualmente. No congelar estas cifras como métricas en vivo.
