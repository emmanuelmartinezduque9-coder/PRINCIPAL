# Nombres de marca de Emmanuel

## Comprender la referencia

- Consultar el perfil/enlace real con herramientas disponibles y examinar las publicaciones o tienda enlazada necesarias para identificar el producto. El nombre de usuario no basta para saber qué vende.
- Conservar URL del perfil, publicación concreta y fecha de consulta como procedencia. Separar la marca competidora del nombre elegido para la marca propia.
- Si el perfil vende productos distintos y no hay uno indicado inequívocamente, preguntar solo cuál; si no es accesible, probar las fuentes públicas enlazadas y pedir un enlace de publicación o captura únicamente si sigue siendo imposible identificarlo. Nunca inventar prestaciones o variantes.
- Usar el mercado indicado por Emmanuel o fijado explícitamente en el encargo. Si falta, preguntar por él antes de elegir un nombre localizado; no asumir Alemania para todos los productos.
- Si indica varios países, elegir y documentar el nombre adecuado para cada mercado solicitado; un nombre compartido solo si funciona de forma natural en esos idiomas. No reducir el encargo a un solo país. La web competidora identifica el artículo, no determina nuestra identidad gráfica: logos, paleta y embalaje propios según nuevo-producto.

## Selección y comprobación

Comparar internamente varias opciones por pertinencia, naturalidad local, recuerdo y diferenciación. No mostrar la lista salvo petición. Consultar las cuentas existentes para evitar duplicados propios. Hacer una búsqueda pública acotada del candidato y categoría para detectar coincidencias evidentes; descartar conflictos claros y elegir otra opción sin otra votación.

No afirmar «marca libre», disponibilidad de dominio/usuario ni autorización legal a partir de esa búsqueda. Si no se puede comprobar, registrar «coincidencias no verificadas»; si un riesgo claro impide una elección razonable, explicar el bloqueo concreto.

Registrar en la ficha del producto: nombre público, identificador interno, país/idioma, descripción verificada, perfil y publicación de origen, razón breve de elección, ejemplos históricos que la orientaron, comprobaciones realizadas y limitaciones. Conservar la fuente como competidor/inspiración de la nueva cuenta usando el registro existente; no sustituir el perfil por la marca propia ni inventar persistencia.
